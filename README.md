# SIH26082 – Air Pollution–Weather Coupled Forecasting System

Backend API for the SIH26082 Smart India Hackathon project, focused on air-pollution and weather monitoring and 72-hour forecasting for Delhi NCR.

## Project Overview

This backend provides APIs for:

- User registration and login
- JWT-based authentication
- User profile access
- Weather data
- Air-quality / pollution data
- Delhi NCR monitoring locations
- Combined monitoring data
- Forecast API interface for AI/ML predictions

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Axios
- Helmet

- CORS

## Setup

Clone the repository and install dependencies:

```bash
npm install
```

Create a `.env` file in the project root:

```env
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/sih_backend
JWT_SECRET=your_secret_key
```

Start the development server:

```bash
npm run dev
```

Or start normally:

```bash
npm start
```

The backend runs on:

```text
http://localhost:5000
```

## Main API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/users` | Register user |
| POST | `/api/auth/login` | Login and receive JWT |
| GET | `/api/profile` | Get protected user profile |
| GET | `/api/weather` | Get weather data |
| GET | `/api/aqi` | Get air-quality/pollution data |
| GET | `/api/locations` | Get NCR locations |
| GET | `/api/locations/:id` | Get a specific location |
| GET | `/api/monitoring/:locationId` | Get combined monitoring data |
| POST | `/api/forecast` | Submit forecast/model output |
| GET | `/api/forecast/:locationId` | Get stored forecast |

## Delhi NCR Locations

The current monitoring locations are:

- Delhi
- Noida
- Ghaziabad
- Gurugram
- Faridabad

## Forecast and AI/ML Integration

The `/api/forecast` endpoint acts as the interface for the AI/ML team.

The final 72-hour pollution/AQI prediction can be generated by the project's modelling pipeline and submitted to the backend through the forecast API.

Potential modelling components such as WRF, chemistry/chemical transport modelling, and machine-learning models can be integrated on the AI/ML side and connected through this interface.

## Security

- Passwords are hashed using bcrypt.
- JWT is used for protected APIs.
- `.env` is excluded from Git using `.gitignore`.
- `node_modules` is excluded from Git.

## Important

Do not upload `.env`, JWT secrets, passwords, API keys, or `node_modules` to GitHub.
